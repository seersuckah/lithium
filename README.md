## English summary

Lithium 7 is a single-executable Windows 11 toolkit: system snapshot, reversible registry tweaks, services & startup control, per-application firewall isolation (NetBlock), Windows Update via WUA, disk cleanup, file association export/import, and a local action journal.

**Closed source, free of charge, AS IS.** There is no installer and no cloud account. The program does leave a documented trace on the machine (registry keys and a log file next to the executable) — see [Что Lithium пишет в систему](#что-lithium-пишет-в-систему).

Requires **Windows 11 25H2 Pro or newer**, x64, and **Microsoft Edge WebView2 Runtime**. Always verify the SHA256 published on the Release page before running. Full legal terms: [EULA.md](EULA.md).

## Зачем это

Lithium — настольный инструмент из одного исполняемого файла. Вы выбираете действия сами, видите фактическое состояние системы, откатываете то, что подлежит откату, и несёте **полную ответственность** за результат на своей машине.

Типичные сценарии:

- **перенести ассоциации файлов** с одной системы на другую — экспорт снимка, переустановка Windows, импорт;
- посмотреть, **что** сейчас в системе (снимок), прежде чем менять хоть что-то;
- точечно применить **твики** (приватность, UAC, hosts, Edge/Copilot/Recall и другие по каталогу в UI) и откатить их обратно;
- отрезать конкретной программе интернет через **NetBlock** (правила Windows Firewall);
- навести порядок в **автозагрузке** и **службах**;
- найти и поставить **обновления Windows** через Windows Update Agent;
- **очистить** дисковые цели из каталога cleanup;
- посмотреть **журнал** того, что Lithium делал с машиной.

## Обратимость: что откатывается и что нет

Это главное свойство программы, поэтому границы обозначены прямо.

**Откатывается точно.** Твики. Перед первым касанием ключа Lithium снимает его исходное значение и хранит рядом с собой. Откат возвращает состояние, которое было **до первого касания Lithium** на этой машине. В UI есть общий откат всех применённых твиков.

**Возвращается вручную.** Службы и автозагрузка. Программа показывает состояние и позволяет включить обратно любой элемент, который вы выключили.

**Не откатывается по природе действия.**

- **Очистка диска** — удалённые файлы удалены.
- **Обновления Windows** — установленный пакет остаётся установленным; удаление обновлений выполняется средствами Windows.
- Отдельные системные операции, помеченные в UI как необратимые. Для них программа запрашивает явное подтверждение и честно отказывает в откате вместо имитации.

## Что Lithium пишет в систему

Исходный код закрыт, поэтому след программы описан здесь целиком. Всё перечисленное видно в regedit и в проводнике, проверяется без доверия автору на слово.

| Место | Что там лежит |
|-------|---------------|
| `HKCU\Software\Lithium` | Отметка принятия EULA: `EulaAccepted`, `EulaVersion` |
| `HKLM\SOFTWARE\Lithium\State` | Исходные значения реестра, снятые перед применением твиков, — то, чем работает откат. Записи зеркалят реестровые с сохранением типа и читаются глазами |
| `lithium.log` рядом с exe | Человекочитаемая лента действий |
| Ключи, которые меняет конкретный твик | Перечислены в карточке твика в UI перед применением |
| Правила Windows Firewall | Создаются NetBlock, имена правил начинаются с `LithiumNB.` |

**Полное удаление следа.** Откатить все твики в UI, снять правила NetBlock, удалить ветки `HKLM\SOFTWARE\Lithium` и `HKCU\Software\Lithium`, удалить папку с `lithium.exe` и `lithium.log`. После этого от программы в системе не остаётся ничего.

Звание «портативная» тут применимо с оговоркой: инсталлятора нет, файл один, реестровый след существует и описан выше. Инструмент, который меняет систему, обязан помнить, что именно он изменил.

**Сеть.** Обращения наружу происходят в трёх местах: Windows Update (WUA), загрузка WebView2 Runtime средствами Windows при его отсутствии, и обновление hosts-блока из вшитого списка доменов (сам список зашит в бинарь, скачивание не выполняется). Продуктовой телеметрии «в облако» нет. Проверяется Wireshark за пять минут.

## Установка и запуск

1. Откройте **[Releases](../../releases)** и скачайте asset **только** оттуда, для нужного тега версии.
2. Сверьте **SHA256** скачанного файла с эталоном на странице того же релиза (см. ниже). Расхождение означает, что файл повреждён, недокачан или подменён — **запускать нельзя**.
3. Положите `lithium.exe` в удобную папку. Папки с принудительной синхронизацией (OneDrive) лучше обойти стороной: программа пишет журнал рядом с собой.
4. Запустите **от имени администратора**, если планируете менять систему.
5. При первом запуске прочитайте условия и примите их:
   - **GUI:** подсказка на пластине согласия (принятие выполняется **правым кликом**);
   - **CLI:** `lithium eula`, затем введите `ПРИНИМАЮ` (регистр не важен; Enter или `y` не подходят).
6. Отметка согласия ложится в `HKCU\Software\Lithium` (`EulaAccepted`, `EulaVersion`).

Репаки, «тихие установщики» и сборки «с твиками от блогера» — чужой код под именем, которому вы решили доверять. См. [EULA](EULA.md) §§ 5–6.

Антивирусы периодически реагируют на инструменты, которые трогают реестр, Firewall и WUA. Для этого класса программ такое поведение ожидаемо. Якорь целостности здесь один — SHA256 на странице релиза.

## Проверка целостности (SHA256)

Каждый официальный asset сопровождается SHA256. У каждой версии свой хеш: `7.1.5` и `7.2.0` различаются полностью. Сверяйте только с эталоном той страницы релиза, откуда качали.

**Правило.** Хеш файла на диске совпадает с опубликованным символ в символ. Любое расхождение означает другой файл.

Эталон лежит на странице конкретного релиза: строкой в описании (`SHA256 (lithium-….exe) = …`) и/или отдельным asset `*.sha256` рядом. Хеш и файл относятся к одному и тому же asset: хеш от exe не подходит для zip и наоборот.

### Как посчитать (PowerShell)

```powershell
Get-FileHash -Algorithm SHA256 .\lithium.exe
```

Сравните поле `Hash` со строкой на GitHub без учёта регистра (A–F и a–f равнозначны). Значение имеют 64 hex-символа, имя файла и пробелы в расчёт не входят.

### Чеклист

- [ ] Скачано только с официального [Releases](../../releases)
- [ ] SHA256 взят с той же страницы и того же тега
- [ ] `Get-FileHash` совпал с эталоном
- [ ] Только после этого — запуск

Пересборка файла без публикации нового релиза не выполняется: одна версия — один файл — один опубликованный хеш.

## Безопасность и здравый смысл

- Снимок и журнал существуют для того, чтобы ими пользовались. Кнопку «применить всё» жать без понимания пунктов не стоит.
- Твики и службы способны сломать привычное поведение Windows, корпоративные политики и лицензии стороннего ПО.
- NetBlock режет сеть конкретному пути. Ошиблись путём — отрезали не то.
- Cleanup удаляет данные без возможности вернуть их.
- Установка обновлений через WUA принимает условия Microsoft для выбранных пакетов в рамках сессии агента.
- На чужой или рабочей машине без соответствующих полномочий программу использовать нельзя. Это прямо записано в EULA.

Автор не обязан чинить систему после экспериментов. Программа поставляется AS IS.
